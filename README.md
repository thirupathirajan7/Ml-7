# Credit Card Fraud Detection Using Machine Learning

## 📌 Project Overview
Credit Card Fraud Detection is a machine learning project that identifies potentially fraudulent credit card transactions. It uses a **Random Forest Classifier** to classify transactions as genuine or fraudulent based on the transaction data.

The main goal of this project is to help detect suspicious transactions and reduce financial fraud.

## 🎯 Objectives
- Analyze credit card transaction data.
- Understand genuine and fraudulent transaction patterns.
- Train a machine learning model to detect fraud.
- Evaluate model performance using different metrics.
- Identify important features that influence predictions.

## 🛠️ Technologies Used
- **Python** – Programming language
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Data visualization library
- **Scikit-learn** – Machine learning and model evaluation
- **Google Colab** – Development environment

## 📂 Dataset
The project uses a dataset named `creditcard.csv`.

The dataset contains transaction information and a target column named `Class`:
- `0` – Genuine transaction
- `1` – Fraudulent transaction

The dataset is loaded and analyzed to understand its structure, missing values, and class distribution.
